Entity: bg_color

  • File: bg_color.v
  • Title: Generador de Color de Fondo
  • Author: Brayan Solís

Diagram

Description

Módulo combinacional que calcula el color RGB332 de cada píxel del paisaje dinámico según la coordenada (x, y) y la fase del día.

El fondo se renderiza en capas (de fondo a primer plano): cielo → estrellas → astro (luna/sol/halos) → nubes → montañas → suelo/río. Cada capa sobreescribe el color de la capa anterior si el píxel pertenece a ella.

Codificación de fase: DAWN=00 madrugada, DAY=01 día, DUSK=10 tarde, NIGHT=11 noche. El campo astro_cy desplaza verticalmente la posición del sol o la luna.
